# B-roll drop folder

Put optional footage here and the pipeline composites it **behind** the telemetry
overlays automatically:

- Video: `.mp4`, `.mov` (looped/trimmed to fit)
- Stills: `.jpg`, `.jpeg`, `.png` (slow Ken Burns pan)

Files are used in alphabetical order, each one getting an equal slice of the 50 s.
Every clip is scaled/cropped to 1080x1920, graded for high contrast (crushed blacks,
desaturated, teal-shifted shadows) and given a dark broadcast vignette. The navy
graphics layer then becomes semi-transparent so the footage reads through.

Only use footage you have the rights to publish (your own, agency-licensed, or
public-domain sources such as government/NDRF/IMD handouts).

# B-roll drop folder

Put `.mp4` / `.mov` / `.jpg` / `.png` files here (sorted by filename = playback order).
When present, `make_short.py` cuts them into equal slots across the 50 s, crops to 9:16,
applies a high-contrast documentary grade (crushed blacks, desaturated, crimson-warm
curves) and composites the data overlays + kinetic type over it at 85% opacity.
Images get a slow Ken Burns push-in. With no files here, a textured charcoal plate is used.

Only use footage you have the rights to publish.

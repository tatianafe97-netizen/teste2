# B-roll drop folder

Put any `.mp4` / `.mov` / `.webm` clips or `.jpg` / `.png` stills here.

* Files are sorted by name and assigned to scenes in order (scene 1 gets the
  first file, scene 2 the second, …, wrapping around if there are fewer than 4).
* Video is scaled/cropped to 1080x1920, looped to fill the scene and graded dark
  (desaturated, navy-tinted, vignetted) so the telemetry graphics stay readable.
* Stills get a slow Ken Burns push-in with the same grade.
* With an empty folder (or `--no-broll`) a procedural radar-grid background is used.

Only use footage you have the rights to publish.
